FibrilGen API Reference

Choose version:

FibrilGen is a software project aimed at building cross-beta structures. The source code is provided at here. The content below explains different levels of structural and positional manipulations of a cross-beta structure, explicitly described as:

peptide -> 2 x 2 unit -> cross-b fibril

On the peptide level, users can create a peptide molecule by get_b_strand and manipulate the side-chain angles by set_chi_angle.

On the 2 x 2 unit level, users can assign a peptide molecule and a linear segment to arrange four copied peptide molecules into a bilayer structure. Firstly, assign the peptide molecule and the linear segment, using create_pep_unit(pep_filename: str, start_residue_index: int, end_residue_index: int, is_face_side: boolean) as:

>>> unit_first = create_pep_unit('pep',2,8,0)

Secondly, create a sheet object from the unit object as:

>>> sheet = create_sheet(unit_first)

To assemble a bilayer structure with assigned peptide alignments and the number of unit repeats, use sheet.build_a_plain_sheet.

On the cross-b fibril level, users can assign geometrical parameters to vary cross-beta structures that the given 2 x 2 unit assemble into. Firstly, assign the peptide molecule and the linear segment for the input bilayer structure, using create_sheet_unit(len_pep: int, num_peps: int, start_residue_index: int, end_residue_index: int) as:

>>> unit_second = create_sheet_unit(10,9,2,9)

Then, create a fibril object from the unit object as:

>>> fibril = create_fibril(unit_second)

To assemble a cross-beta fibril structure with assigned unit stacking and twisting patterns, use fibril.build_a_flat_sheet, fibril.build_a_stacked_sheet, fibril.build_a_rod, fibril.build_a_stacked_rod, fibril.build_a_ribbon or fibril.build_a_stacked_ribbon.

get_b_strand

Create a beta-strand molecule from the input amino acid sequence. Protonation states are assigned at pH 7.

get_b_strand(seq)

Arguments

  • seq(str) - A sequence of starndard amino acids

Example

>>> get_b_strand('FEFKFEFK')

Return to the top.

set_chi_angle

Set a chi angle for the input peptide molecule. The chi angle is defined by a dihedral angle.

set_chi_angle(resi, atom1, atom2, atom3, atom4, angle)

Arguments

  • resi(int) - Residue index
  • atom1(str) - First atom for the dihedral angle
  • atom2(str) - Second atom for the dihedral angle
  • atom3(str) - Third atom for the dihedral angle
  • atom4(str) - Fourth atom for the dihedral angle
  • angle(float) - Dihedral angle

Example

>>> set_chi_angle(1,'n','ca','cb','cg',-20)

Return to the top.

sheet.build_a_plain_sheet

Create a bilayer structure for the input peptide alignments and the number of repeated alignements

sheet.build_a_plain_sheet(peptide_alignment, is_face_to_face, num_units)

Arguments

  • peptide_alignment(str) - Appended parallel (p) or antiparallel (a) backbone alignments for two beta-sheets. Assign the intra-sheet alignment of the inner beta-sheet; the inter-sheet alignment between the inner and outer beta-sheets; and the intra-sheet alignment of the outer beta-sheet. There are eight possible combinations: 'aaa', 'apa', 'aap', 'app', 'paa', 'ppa', 'pap', and 'ppp'.
  • is_face_to_face(boolean) - True if two sheets are aligned face-to-face, else False.
  • num_units(int) - Number of unit repeat

Example

>>> build_a_plain_sheet('ppa',1,5)

Return to the top.

fibril.build_a_flat_sheet

Create a sheet structure by repeating the 2 x 2 unit along the vertical axis.

fibril.build_a_flat_sheet(num_units)

Arguments

  • num_units(int) - Number of unit repeat along the vertical axis

Example

>>> fibril.build_a_flat_sheet(5)

Return to the top.

fibril.build_a_stacked_sheet

Create a stacked sheet structure by repeating the 2 x 2 unit along the vertical axis and perpendicular to the vertical axis.

fibril.build_a_stacked_sheet(k_matrix, num_units)

Arguments

  • k_matrix(list) - A binary matrix assigning whether a 2 x 2 unit is presented on the fibril cross-section
  • num_units(int) - Number of unit repeat along the vertical axis

Example

>>> fibril.build_a_stacked_sheet([[0,1],[1,1]],5)

Return to the top.

fibril.build_a_rod

Create a rod structure by an initial helical twist and repeating the 2 x 2 unit along the vertical axis.

fibril.build_a_rod(tilt_angle, num_units, twist_sign)

Arguments

  • tilt_angle(float) - Initial tilt angle to rotate the fibril
  • num_units(int) - Number of unit repeat along the vertical axis
  • twist_sign(int) - Assigned to 1 for left-handed twist, and -1 for right-handed twist

Example

>>> fibril.build_a_rod(20,25,1)

Return to the top.

fibril.build_a_stacked_rod

Create a stacked rod structure by confined stacking on the fibril cross-section, an initial helical twist, and repeating the 2 x 2 unit along the vertical axis.

fibril.build_a_stacked_rod(tilt_angle, k_matrix, num_units, twist_sign)

Arguments

  • tilt_angle(float) - Initial tilt angle to rotate the fibril
  • k_matrix(list) - A binary matrix assigning whether a 2 x 2 unit is presented on the fibril cross-section
  • num_units(int) - Number of unit repeat along the vertical axis
  • twist_sign(int) - Assigned to 1 for left-handed twist, and -1 for right-handed twist

Example

>>> fibril.build_a_stacked_rod(10,[[0,1],[1,1]],15,1)

Return to the top.

fibril.build_a_ribbon

Create a ribbon structure by an initial helical twist, and repeating the 2 x 2 unit along the vertical axis.

fibril.build_a_ribbon(tilt_angle, radius, num_units, twist_sign)

Arguments

  • tilt_angle(float) - Initial tilt angle to rotate the fibril
  • radius(float) - Initial radius to rotate the fibril
  • num_units(int) - Number of unit repeat along the vertical axis
  • twist_sign(int) - Assigned to 1 for left-handed twist, and -1 for right-handed twist

Example

>>> fibril.build_a_ribbon(10,30,60,-1)

Return to the top.

fibril.build_a_stacked_ribbon

Create a stacked ribbon structure by confined stacking on the fibril cross-section, an initial helical twist, and repeating the 2 x 2 unit along the vertical axis.

fibril.build_a_stacked_ribbon(tilt_angle, radius, neighbouring_stacking_angle, M_stacking, num_units, twist_sign)

Arguments

  • tilt_angle(float) - Initial tilt angle to rotate the fibril
  • radius(float) - Initial radius to rotate the fibril
  • neighbouring_stacking_angle(float) - Angular displacement of units on the fibril cross-section.
  • M_stacking(int) - Number of rotated units on the fibril cross-section
  • num_units(int) - Number of unit repeat along the vertical axis
  • twist_sign(int) - Assigned to 1 for left-handed twist, and -1 for right-handed twist

Example

>>> fibril.build_a_stacked_ribbon(10,30,110,2,20,1)
